## 권장 사양

- 가로 컷: 2400 x 1600 px 내외
- 세로 컷: 1600 x 2200 px 내외
- 용량: 장당 500KB 이하 권장 (Next.js Image 가 자동으로 최적화합니다)
- 확장자를 `.webp` 등으로 바꾸려면 `lib/site.ts` 의 경로만 수정하면 됩니다.

## 사진 순서를 바꾸고 싶다면

`lib/site.ts` 의 `images` 객체에서 경로만 바꾸면 됩니다.
컴포넌트를 수정할 필요가 없습니다.
