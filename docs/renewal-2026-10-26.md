## 검증과 자동 시안 비교 상태

사용자 검토는 다섯 항목 승인과 인물 사진 수정 요청으로 남아 있다. 요청한 원본 컬러 사진을 적용했다. 사용자 대신 검토 화면을 제출하거나 승인 영수증을 작성하지 않았다.

- Impeccable의 엄격한 자동 시안 비교는 `plates` 단계에 열려 있다. 흑백 시안과 원본 컬러 사진의 차이 및 검토 영수증 때문에 강제 진행 요청도 거절됐다. 이를 전체 게이트 통과로 표현하지 않는다.
- 사용자의 명시적인 컬러 수정 요청과 현재 디자인 선택을 구현 기준으로 삼았다. 실제 렌더링의 독립 검토 결과는 `.impeccable/review/finish-review.md`에 별도로 기록한다.
- Next.js 운영 빌드, TypeScript, git diff 공백 검사를 통과했다. UI 감지기는 한 번 실행해 0건이었다. 새 이미지 출처 검사: 4개, 누락 0개.
- 320×610, 390×844, 1440×1000 화면에서 가로 넘침과 이미지 로드를 확인했다. 모바일 메뉴·Escape·포커스 복귀, 세 트레이너 상세 프로필, 위치 안내까지 이동 후 본문 유지 동작을 확인했다.
- 독립 검토의 첫 판정은 `rebuild`였다. 인용문과 상담 버튼에 실제 생성 래스터 잉크 재질을 적용하고, 표제 위의 지역명을 헤더 로고의 보조 표기로 옮겼다. 인용문·버튼 문자는 HTML로 유지한다. 320px에서도 두 상담 버튼 너비는 같다.
- 실제 캡처와 자동 비교 자료는 `.impeccable/review/`에 있다. hero-repro 비교 60%, 전체 PC 화면 비교 47%로 수치 게이트 통과는 아니다. 원본 컬러 사진·새 로고·기기별 재배치의 차이가 포함된다. 실제 대조 화면과 영역 쌍을 독립 검토에 제공했다.
- 독립 최종 검토에서 시각 수정은 모두 해결됐고 추가 UI 수정은 없었다. 전체 판정은 엄격한 단계 기록 미완료만을 이유로 `fix`다. 이를 `ship` 또는 전체 스킬 통과로 바꾸어 보고하지 않는다. 실제 화면 검토와 사용자 배포 지시에 따른 운영 배포는 이 도구 상태와 구분한다.

## 구현 시 참고

한글과 기울어진 두 줄 인용문에서 자동 글꼴 측정이 글자를 묶어 읽어, 라틴 글꼴과 과도한 크기를 제안했다. `.impeccable/build/font-match/` 비교 이미지를 확인했다. 실제 한글은 승인된 시안의 굵은 형태와 줄 구성을 기준으로 맞추고, 로컬 Black Han Sans·Pretendard를 사용할 수 있다. 자동 측정 결과를 그대로 한글에 적용해 얇은 글자로 바꾸지 않는다.
